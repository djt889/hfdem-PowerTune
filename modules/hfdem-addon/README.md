# hfdem附加模块 v1.0.0

作者：**Jiuxia**

感谢 **@温柔浩** 提供原模块基础；感谢 **@Amktiao** 提供 5.15 内核优化模块。

## 功能边界

本模块保留基础附加优化，不包含动态超频、Scene/CTS 监听或手动 Boost：

- ZRAM 主选标准 `lz4`，写入后回读验证；不支持或失败时按能力安全回退。
- `vm.swappiness=60`，并保留既有 THP、MGLRU、网络、后台、I/O、IRQ、LPM 等已验收能力。
- 保留 Joyose/MIUI 净化链路，但不包含 CPU/GPU/总线调频命令。
- 仅在 `5.15*` 内核尝试加载第三方 KO；Binder 替换失败时回滚，其他 KO 逐项隔离失败。
- WebUI 为只读诊断，不写入调频参数。

## 5.15 第三方 KO 来源

`ko/` 中的 5.15 KO 来自 **@Amktiao 的 5.15 内核优化模块**。这些预编译文件与具体内核兼容性相关；模块只在 5.15 系列尝试加载，并不保证适配所有设备。

## 安装与升级

在 Magisk、KernelSU 或 APatch 管理器中刷入 ZIP 后重启。模块 ID 保持 `hfdem_savemode`，可覆盖升级此前同 ID 版本。可与 `动态超频模块`（ID `hfdem_dynamic_oc`）同时安装。

## 安全说明

ZRAM 会进行“能力枚举 → 写入 → 回读 → 回退”；5.15 Binder 替换会检查恢复条件并在失败后尝试恢复原模块。刷入前仍建议备份并确认设备具备救砖条件。
